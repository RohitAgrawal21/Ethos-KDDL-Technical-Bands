Probability model

Drill down: the six parameters

Show history of:
How it is built. Layer 1 (posture) is a fixed rule count: 5 yes/no trend checks plus a stretch flag (|z| ≥ 2). It describes the chart; it does not predict. Layer 2 (probability): for each of 6 parameters, the stock's own history gives P(close 10 sessions later is higher) for the current bucket, shrunk toward the stock's overall base rate (20 pseudo-observations). The composite averages the six log-odds shifts with equal weights (decided in advance, not fitted). Everything is walk-forward: on any date it only uses outcomes already known then. Bollinger Bands, +1/+2 SD and the 20-day average are one parameter (z20), because %B = 0.5 + z20/4: they carry the same information. AUC is the walk-forward test of skill: 0.50 = coin flip, above 0.58 = useful, below 0.50 = worse than a coin flip.

3. The maths, on a day you pick

Date: recomputed in your browser from the closes shown, then checked against the exported value
The 20 closes in the window
SMA_n = mean of the last n closes C (n = 20, 50, 200) % deviation_n = C / SMA_n - 1 (distance only; ignores volatility) SD_n = population standard deviation (divide by n) of the closing PRICES over the same n days z_n = (C - SMA_n) / SD_n (distance in standard deviations) Bollinger(20,2): Upper = SMA20 + 2*SD20, Lower = SMA20 - 2*SD20, %B = (C - Lower)/(Upper - Lower), bandwidth = (Upper - Lower)/SMA20
A close outside the bands is exactly |z20| ≥ 2. The bands are the z-score drawn on the price chart; %B and z20 carry the same information (%B = 0.5 + z20/4).

Period: Horizon: Events ≥ 20 sessions apart. Excess = signal mean minus the all-days average over the same period and horizon.
